# 两分钟现场演示

开始前打开 `启动应用.cmd`，保持启动窗口。进入全景，清除搜索，关闭环境音。没有 API 密钥也能完成所有主要演示。

| 时间 | 操作 | 讲述要点 |
| --- | --- | --- |
| 0–20 秒 | 展示二维全景，指向六种颜色与 500 个光点 | “每首歌是一座岛。我们把生活里散落的音乐记录，变成一个能亲自探索的世界。” |
| 20–35 秒 | 切换「音乐群岛 3D」，轻拖旋转 | “同一份歌单有两个入口：二维便于发现关系，三维让次数成为地形。” |
| 35–55 秒 | 向导点击「最高地标」 | “No Surprises 是最高地标，299 次；最后播放日期是 2020-11-07。大小是累计次数，亮度是相对数据日期的静默时间。” |
| 55–75 秒 | 点击「另一座双岛」，再用「跨海大桥」 | “同歌的 Live 版是另一座岛。97 对双岛由歌名与艺人匹配；Radiohead 则连接 2020 与 2023 两个章节。” |
| 75–95 秒 | 打开「发现」，展开一条数据依据；移动时间滑块 | “每条发现都能核验。我们有最后播放日期，所以只做记录切片，不捏造完整历史。” |
| 95–110 秒 | 点击一首歌，写下短记忆并收藏 | “数字能留下次数，只有你能解释那段生活。这里的故事由本人书写。” |
| 110–120 秒 | 点击「导出世界」，展示 PNG / JSON 选项 | “世界可以带走，也可以继续生长。它不是一次性回顾，而是可探索、可保存的记忆空间。” |

也可直接使用左侧「跟随回声漫游」的六站路线；每站都有定位与叙事提示。

## 评委体验

建议先让评委选择一位熟悉的艺人，搜索后点击歌曲，再给这座岛写下自己的记忆。也可导入符合五字段格式的 CSV。数据在本机处理，默认不会上传。

## 常见现场问题

- **断网**：已编译版本的视图、导览、导入、笔记与导出均可用。外部音乐搜索和在线 AI 需要网络。
- **不能播放歌曲**：源 CSV 没有音源。点击「关联本地音频」选择自己已有的 MP3/WAV 等文件；环境音是合成声音，不是歌曲录音。
- **三维无法开启**：使用二维回声之城，核心数据与交互相同。
- **投影字太小**：使用浏览器适当缩放，或展开对应发现 / 歌曲详情。关闭不需要的图层，让重点更清楚。
- **在线 AI 没有选项**：服务器未配置密钥。默认本地导览仍然完整；不要在台上把规则导览描述为已调用大模型。
- **重复启动 / 端口占用**：再次双击会打开已有应用；端口被其他程序占用时会自动选择可用端口，以启动窗口里的实际地址为准。
